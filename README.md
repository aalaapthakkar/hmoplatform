# HMO Platform

A web app for UK HMO landlords, rent to rent operators and letting agents to manage shared houses room by room.

See [CLAUDE.md](./CLAUDE.md) for the stack, rules and commands.

## Getting started

1. Install dependencies: `npm install`
2. Copy `.env.example` to `.env.local` and fill in your Supabase values.
3. Apply database migrations: `npm run db:migrate`
4. Start the dev server: `npm run dev`, then open http://localhost:3000
